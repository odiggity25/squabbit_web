Multiple Tournament Admins

Multiple Admins is a Tournament Pro feature that lets you share the work of running your tournament by giving other members admin access. Instead of everything landing on one person, you can spread the responsibility across a small team, so a big event doesn’t depend on any single organizer being available.

What admins can do

Once a member is an admin, they can help run the tournament right alongside you. Admins have access to the tools that keep an event moving, including:

  • Creating and editing tournament rounds and the schedule
  • Entering and adjusting scores
  • Managing players and the roster
  • Changing the tournament’s settings

In short, an admin can handle the day to day tasks that would otherwise fall to you, so the tournament doesn’t rely on any one person being on hand.

How to add an admin

Adding an admin only takes a moment. Open your tournament, go to the players or roster list, then tap the member you’d like to promote. From there, open their role options and choose Admin, and they’ll immediately gain admin access. The same picker also has Owner, Player, and Spectator roles.

The member doesn’t need to do anything on their end. The next time they open the tournament, they’ll see the admin tools available to them.

Tip: You can change or remove a member’s admin role at any time. If someone steps away from helping out, just open their profile again and switch the role back.

Why it helps

A large charity or corporate event is a lot for one organizer to run alone, with players to check in, scores to enter and last-minute changes to sort out on the day. Multiple Admins lets you split that work across a committee, so no single person is stuck doing everything at once. Each admin can pitch in with the parts they’re best placed to handle, and the tournament keeps running smoothly whether or not any one person is free.

Unlocking Multiple Admins

Multiple Admins is part of Tournament Pro. Tournament Pro can be bought as a yearly subscription or as a one-time unlock for a single event, so you can pick whichever suits how often you run tournaments.
