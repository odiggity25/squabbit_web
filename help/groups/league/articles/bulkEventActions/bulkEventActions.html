Bulk Event Actions

Bulk Event Actions is a League Pro feature that lets you act on many events at once, instead of opening them one at a time. If your league has a full season of events, this saves you from repeating the same change again and again across each event card.

What you can do in bulk

Bulk Event Actions covers the changes you make most often to a run of events:

  • Publish: take several draft events and publish them together, so they all become visible to your players at the same time.
  • Schedule go-live: set several draft events to publish automatically, a set number of days before each event’s own date, instead of publishing them right now.
  • Schedule announcement: for events that are already published, schedule when members are notified, so each announcement is sent a set number of days before its own event date.
  • Complete: mark several events as completed in one step, once they’ve been played and scored.
  • Cancel: cancel several events together when plans change and they’re no longer going ahead.
  • Delete: permanently remove several events at once.

The actions available depend on which events you’ve selected: drafts can be published or scheduled to go live; published events can have their member announcement scheduled or be marked completed; and cancel or delete apply more broadly. Whatever you pick is applied to every selected event at once, so you choose the outcome once and Squabbit handles the whole group.

How it works

Everything happens from your league’s Events tab.

  • Open your league and tap the Events tab at the top.
  • Enter selection mode (the mode that lets you tick off more than one event at a time).
  • Select the events you want to act on.
  • Choose the action to apply: publish, schedule go-live, schedule announcement, complete, cancel, or delete.

Squabbit then applies your chosen action to every selected event at once, and you’re returned to the Events tab.

Some actions open a short follow-up dialog. Choosing Schedule go-live, for example, lets you set how many days before each event’s date it should publish, and at what time. Each selected draft then goes live on its own schedule.

Tip: You can still open and edit any individual event afterwards. Bulk actions are just a faster way to make the same change across several events at once.

When it helps

Bulk Event Actions is most useful at the points in a season where you’re touching a lot of events together:

  • At the start of a season: if you’ve set up a batch of draft events ahead of time, you can publish them all together when you’re ready to open the season to your players.
  • At the end of a season: once a run of events has been played and scored, you can mark them all completed in one step.
  • When plans change: if a stretch of events won’t go ahead (a break in the schedule, a change of venue, a weather washout), you can cancel several of them at once instead of handling each one separately.

Unlocking Bulk Event Actions

Bulk Event Actions is part of League Pro. One subscription unlocks it for every league you run, so you don’t need a separate purchase per league.

Once League Pro is active, the bulk actions become available in the Events tab of any of your leagues automatically.
