Season Schedule Builder

The Season Schedule Builder is a League Pro feature that creates a whole season of events in one pass, instead of copying events one at a time. It runs as a short Events builder wizard: pick a template, set the schedule, and (optionally) generate tee times, and Squabbit lays out and creates every event for you.

Opening the builder

From your league’s Events tab, tap the green + button and choose Create multiple events. That opens the Events builder, which walks you through three steps.

Step 1: Event template

Every event in the season is built from one template. Choose Start from scratch to build the template from a blank event, or Copy an existing event to base it on one of your league’s events. The template’s format, games, fees and settings carry into every generated event.

Step 2: Schedule

Set the start date, choose the frequency (every week, every 2 weeks, monthly, or every few days), and set the number of events to create. Squabbit lays out all the dates from there.

Step 3: Tee times & matches

This step is optional. Turn on Set them up now to generate tee times for every event as it’s created, then set the tee-off time, the time between tee times, and how many tee times per event. You can also switch on Add players to the tee times to assign your league members automatically, or leave it off to create empty tee times to fill in later.

Finish

When everything looks right, tap Create & schedule and Squabbit builds the whole batch of events at once. Each event can still be opened and edited afterwards, just like any other event.

Tip: Because every generated event is a copy of the template, get that first event (format, course, fees, games) exactly right in step 1 before you continue. Every event copies it.

Unlocking the Season Schedule Builder

The Season Schedule Builder is part of League Pro. One subscription unlocks it for every league you run, so you don’t need to pay per league.
