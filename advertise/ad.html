Track installs in your own tool (optional)

Using an attribution link (like an AppsFlyer OneLink or Adjust link)? Add these placeholders and we fill them in on every tap, so installs show up in your own dashboard, credited to Squabbit:

  • {source} — always squabbit
  • {clickid} — a unique id per tap, so each click matches one install
  • {adid} — this ad’s id
  • {platform} — ios, android, or web
  • {ts} — the time of the tap

Drop them in using your tool’s own parameter names (AppsFlyer uses pid for source and c for campaign). Example:

https://yourbrand.onelink.me/abcd?pid={source}&c={adid}&clickid={clickid}

Your traffic will appear in your dashboard under source squabbit.
